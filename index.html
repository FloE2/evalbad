Sauvegarde

Les notes restent dans ce navigateur, mais elles disparaissent si le cache est vidé. Cliquez sur 💾 Enregistrer sur mon PC (ou Ctrl+S) à la fin de chaque séance. Pour tout récupérer, utilisez 📂 Ouvrir et choisissez ce fichier.

Importer des élèves

Copiez les colonnes depuis Excel ou Pronote et collez-les ci-dessous, ou choisissez un ou plusieurs fichiers Excel (.xlsx) ou .csv. Si le fichier n'a pas de colonne CLASSE, le nom du fichier sert de classe (ex. « 4A.xlsx » → 4A). Colonnes attendues : NOM / PRÉNOM / CLASSE / SEXE (avec ou sans ligne d'en-tête). Plusieurs classes peuvent être importées d'un coup.
